# ARES / Noesis

ARES is a scientific research workbench built around traceable evidence. The current development build preserves the supplied Noesis prototype and adds a fail-closed foundation. It can analyze trusted documents, search an existing corpus, run bounded research jobs, and produce reports with candidate findings. Scientific conclusions still require review.

Run the service and tests in a hosted workspace. See [Deployment](docs/DEPLOYMENT.md), [Engineering progress](docs/ENGINEERING_PROGRESS.md), and the [requirements matrix](docs/REQUIREMENTS.md).
