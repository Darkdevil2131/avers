# Scientific validation

Software tests cover the behavior of the supplied prototype and new security and persistence controls. Connector fixtures do not establish live API access. Heuristic stance, graph hypotheses and policy thresholds do not establish scientific validity. Treat evidence grades and belief scores as uncalibrated. Proposed experiments have no execution results.

Start with materials degradation literature. Freeze a lawful, labeled corpus with study IDs and exact source spans. Measure retrieval recall and citation correctness, then context mismatch, contradiction, dependent-study duplication, retraction handling and abstention. Compare against retrieval-only and agentic RAG baselines on the same corpus and disclose uncertainty. No benchmark claim is made for this milestone.
